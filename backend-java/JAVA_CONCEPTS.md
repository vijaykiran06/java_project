# Java Concepts Demonstrated in JanSeva AI Backend

This document maps core Java & Object-Oriented Programming concepts directly to their real implementations in `backend-java/src/main/java/com/janseva/`.

| # | Java Concept | Where Implemented | Class / File | Why Used |
|---|---|---|---|---|
| 1 | **Classes & Objects** | Domain entities, DTOs, services, controllers | `Grievance.java`, `User.java`, `Department.java`, `Incident.java` | Models real civic governance domain entities and encapsulates their attributes and behaviors. |
| 2 | **Encapsulation** | Private fields with getters/setters and `private final` injected dependencies | `Grievance.java`, `User.java`, `AuthService.java`, `JwtService.java` | Protects internal entity state (e.g., `passwordHash` marked `@JsonIgnore` in `User.java`) and enforces controlled mutations. |
| 3 | **Inheritance** | Multi-level JPA mapped superclass hierarchy | `BaseEntity.java` -> `TimestampedEntity.java` -> `Grievance.java`, `User.java`, `Department.java`, `Incident.java`, `Escalation.java`, `AuditLog.java` | Reuses surrogate primary key `id` and UTC `createdAt` lifecycle callbacks (`@PrePersist`) without duplicating boilerplate. |
| 4 | **Abstraction** | Abstract base classes & service interfaces | `BaseEntity.java`, `TimestampedEntity.java`, `MLService.java`, `TranslationService.java` | Separates high-level business logic from database timestamp mechanics and external HTTP client implementations. |
| 5 | **Interfaces** | Service contracts and Spring Data JPA repositories | `MLService.java`, `TranslationService.java`, `GrievanceRepository.java`, `UserRepository.java` | Enables loose coupling between `ConversationAiService`/`DuplicateService` and the ML transport implementation, making unit testing with Mockito clean. |
| 6 | **Polymorphism** | Interface-based dispatch & subtype substitution | `PythonMLService implements MLService`, `GoogleTranslationService implements TranslationService`, `CustomUserDetails implements UserDetails` | Allows swapping real HTTP ML/Translation services with mock implementations in tests or alternative providers in production. |
| 7 | **Constructors** | Constructor-based dependency injection & entity constructors | `GrievanceService.java`, `ConversationAiService.java`, `JwtService.java`, `Department.java` | Guarantees immutable (`final`) dependencies are initialized before use and supports clean testing without field injection. |
| 8 | **Method Overriding & Overloading** | `@Override` of `UserDetails`, `OncePerRequestFilter`, `CommandLineRunner`, `MLService`; overloaded constructors | `CustomUserDetails.java`, `JwtAuthenticationFilter.java`, `DatabaseSchemaVerifier.java`, `PythonMLService.java`, `ErrorResponse.java` | Customizes Spring Security filter execution, startup schema checks, and provides convenient DTO construction (`ErrorResponse(String)` vs `ErrorResponse(String, String)`). |
| 9 | **Collections Framework** | `List`, `Map`, `LinkedHashMap`, `Collectors.toMap` | `DomainConstants.java` (`List.of`, `Map.of`), `ConversationAiService.java` (`LinkedHashMap`), `GrievanceService.java` (`Map<Long, User>`) | Manages category-to-department mappings, conversation state objects, SLA hour lookup tables, and in-memory user lookup maps. |
| 10 | **Exception Handling** | Custom runtime exceptions + centralized `@RestControllerAdvice` | `ResourceNotFoundException.java`, `BadRequestException.java`, `ForbiddenException.java`, `UnauthorizedException.java`, `MLServiceException.java`, `GlobalExceptionHandler.java` | Translates domain and ML communication errors into consistent HTTP status codes (`400`, `401`, `403`, `404`, `502`, `500`) and JSON `{ "error": "..." }` payloads. |
| 11 | **Java Streams** | Functional filtering, mapping, sorting, and limiting | `GrievanceService.java` (`listGrievances`, `getGrievanceDetail`), `AdminAnalyticsService.java` (`semanticSearch`), `CorsConfig.java`, `GlobalExceptionHandler.java` | Replaces verbose loops with declarative data transformation pipelines for DTO projection, keyword scoring, and validation error formatting. |
| 12 | **JPA / JDBC** | Spring Data JPA entities/repositories + raw JDBC `DataSource` schema check | `entity/*`, `repository/*`, `DatabaseSchemaVerifier.java` | Combines ORM productivity (`JpaRepository`, `@Query`) with direct JDBC `Statement` execution for SQLite `CREATE TABLE IF NOT EXISTS` verification. |
| 13 | **Scheduling / Background Processing** | `@EnableScheduling` + `@Scheduled` periodic SLA escalation monitor | `JanSevaApplication.java`, `SlaService.java` (`scheduledSlaMonitor`) | Runs background SLA breach checks every 30 seconds independently of HTTP request threads. |
| 14 | **Dependency Injection** | Spring IoC constructor injection & `@Bean` configuration | `AppConfig.java`, `SecurityConfig.java`, all `@Service` and `@RestController` classes | Manages bean lifecycles (`RestClient`, `PasswordEncoder`, `JwtService`, repositories) centrally. |
| 15 | **REST API Development** | Spring Web MVC `@RestController` endpoints with `@PreAuthorize` & `@PathVariable` | `AuthController.java`, `GrievanceController.java`, `AiController.java`, `DepartmentController.java`, `IncidentController.java`, `HealthController.java` | Exposes RESTful JSON endpoints matching the existing React frontend contract. |
| 16 | **Java Records & Immutability** | Java `record` DTOs for requests/responses | `AuthDtos.java`, `GrievanceDtos.java`, `AiDtos.java`, `MLDtos.java`, `ErrorResponse.java` | Provides concise, immutable data carriers with automatic Jackson JSON serialization. |
